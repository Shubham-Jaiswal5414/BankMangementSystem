# 🏦 Bank Management System  

A full-stack *Bank Management System* built using *Spring Boot, **Spring Data JPA, and **H2/MySQL Database* for the backend, with a clean *HTML, CSS, and JavaScript* frontend.  
This project helps manage banking operations such as account creation, customer details, and transactions through a simple, responsive interface.

---

## 🚀 Live Demo  

👉 *Frontend Demo (Netlify):* [Live Demo](https://your-bank-management-system.netlify.app/)  
(Note: Only static frontend UI is hosted. Backend must run locally or be deployed separately.)

---

## ✨ Features  

- 🧾 Add, view, and manage bank customers  
- 💰 Handle deposits, withdrawals, and transactions  
- 🔍 Search and view customer account details  
- 🗄 Integrated database (H2/MySQL)  
- ⚡ REST API powered by Spring Boot  
- 🖥 Responsive and simple user interface  

---

## 🛠 Technologies Used  

### 🧩 Backend  
- *Java 17+*  
- *Spring Boot 3.x*  
- *Spring Data JPA (Hibernate)*  
- *H2 / MySQL Database*  
- *Maven*

### 🎨 Frontend  
- *HTML5*  
- *CSS3*  
- *JavaScript (Vanilla JS)*  
- *Bootstrap (optional)*
